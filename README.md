# Лекса

PWA на React для изучения иностранных слов на iPhone.

Сайт: https://irina0110.github.io/Leksa/

## Запуск локально

```bash
npm install
npm run dev
```

## GitHub Pages

Ошибка `GET .../src/main.tsx 404` значит, что Pages отдаёт исходники, а не сборку.

**Исправьте настройки (обязательно):**

1. Откройте https://github.com/Irina0110/Leksa/settings/pages  
2. Source: **Deploy from a branch**  
3. Branch: **main**  
4. Folder: **/docs**  
5. Save  

Подождите 1–2 минуты и обновите сайт с очисткой кэша.
